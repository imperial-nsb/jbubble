    jbubble.shapes.Rect25NegPos ¶

    Bases: FourierPulseShape

    Rectangular waveform: - First 25% of cycle: -1 - Last 75% of cycle: +1

    Implemented as a +1 window of duty D = 0.25, phase-shifted so it begins at 25% into the cycle (i.e., occupies the last 75%).

    jbubble.shapes.Rect75NegPos ¶

    Bases: FourierPulseShape

    Rectangular waveform: - First 75% of cycle: -1 - Last 25% of cycle: +1

    Implemented as a +1 window of duty D = 0.75, phase-shifted to occur at the end (last quarter) of each period.

    jbubble.shapes.Rect95 ¶

    Bases: FourierPulseShape

    Rectangular waveform: - For 0 < t <= 0.95T: -1 - For 0.95T < t < T: +1 With f(0) defined as 0 (which the Fourier series attains as the midpoint at the jump).

    Implemented as a +1 window of duty D = 0.05, phase-shifted to occur at the end of each period.

    jbubble.shapes.Mono95 ¶

    Bases: FourierPulseShape

    Rectangular waveform: - First 95% of cycle: -1 - Last 5% of cycle: 0

    Implemented as a 0-level window of duty D = 0.05, phase-shifted to occur at the end of each period.

    jbubble.shapes.Mono99 ¶

    Bases: FourierPulseShape

    Rectangular waveform: - First 99% of cycle: -1 - Last 1% of cycle: 0

    Implemented as a 0-level window of duty D=0.01, phase-shifted to occur at the end of each period.
